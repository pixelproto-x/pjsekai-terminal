# Dojo parity target

The Dojo renderer targets the public Next-SEKAI visual model and Project SEKAI chart assets. Next-SEKAI provides extended note types, enhanced slides, slot/glow effects, and note particles. The browser player remains a native WebGL implementation rather than Sonolus.

Parity work is focused on stage projection, note geometry, slide connectors, flick directions, judgement feedback, combo/LIFE HUD, and mobile input.
